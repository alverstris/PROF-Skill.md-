Course conventions and source warrants

C1 Hyperbolic definitions: source PDF physical page 2/printed page 1 writes sinh=(e^x-e^-x)/2 and cosh=(e^x+e^-x)/2. The derivative signs and hyperbola equation are preserved exactly. Coordinate letters u,v denote a point while x is the parameter.
C2 Derivative prime: source PDF page 3 writes u', v', y', with respect to x; teaching P005 and P019–P022 state this and distinguish f' evaluated at its input in composition.
C3 Inverse trigonometric notation: source pages 3–5 uses sin^-1 and tan^-1 as inverses, demonstrated by sin y=x and 1/(1+x^2). Teaching P005/P089 maps them explicitly to arcsin/arctan. Principal branches match the baseline's stated intervals. Source arcsine positive root is consistent with that branch; no conflicting convention or user clarification is needed.
C4 Radians: source supplied sin(h)/h limit=1 is the discriminating convention; baseline explicitly supplies radian requirement. Teaching P005/P056/P064 carry it throughout.
C5 Real powers: source page 4 uses ln x, so positive x is required for the displayed proof. Teaching P075–P083 makes x>0 explicit rather than generalising to negative bases. The exponent r is a fixed real number. Integer/rational exceptional domain extensions are acknowledged without assuming one uniform negative-base definition.
C6 Limit increment: source page 4 uses both h and Delta x. Teaching P060 identifies these as the same increment role and distinguishes fixed x from varying nonzero h.
C7 Exponential grouping: source page 5 full image confirms e raised to the whole product x tan^-1 x. Teaching P089–P093 preserves it, then returns from w to original notation.
C8 sqrt: baseline ordinary principal square root; branch sign must be established before replacing cosine/sine with sqrt(1-x^2). P045 and Q4 solution do so.
