Potential local correction identified independently

P012 defines o(h) as an unspecified remainder and then says, 'It is not zero'. A little-o remainder can be identically zero (for example for an exactly linear function). Read literally, the categorical assertion is false. The intended warning is that little-o does not assert zero: wording such as 'It need not be zero' would be accurate. This is a narrow document wording issue, not evidence that the current skill lacks a general technical-correctness requirement.
