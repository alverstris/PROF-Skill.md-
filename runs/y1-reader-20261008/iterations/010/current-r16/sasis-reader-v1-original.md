## Supported defects, concerns and limits

### Supported local definition defects

**D1 — P007, interior-input definition is too weak outside the interval setting.** Saying that an interior input “has allowed points on both sides” does not ensure that c+h is allowed for every sufficiently small positive and negative h, which the following ordinary two-sided difference-quotient argument uses. A domain can contain a point c and some allowed points to its left and right while leaving gaps immediately next to c; ordinary set reasoning from B0030 already exposes the missing condition. The exact missing connection is an allowed interval around c. Suggested narrow correction: “An interior input has a small interval around it consisting entirely of allowed inputs.” Scope/effect: the lesson's actual domains are intervals, and all used interior candidates have such neighbourhoods, so the proof and every downstream example remain supported. This is a definition-scope repair, not a blocked calculation or a demand for untaught topology.

**D2 — P011, least-upper-bound gloss describes only the nonattained cases here.** The phrase “a bound that can be approached arbitrarily closely from below” works for the displayed x on (0,1) and the strict wire case, but as a general definition is narrower than the intended upper-bound concept: for a constant function with output 1 there is a least upper bound 1, yet no output strictly below 1 from which to approach it. This counterexample needs only function/inequality language B0030/B0062 and ordinary logic, not an external theorem. The exact missing allowance is equality/attainment; also make “upper bound” explicit. Suggested correction: “A least upper bound is an upper bound no smaller number can be; it may or may not be attained.” One may then explain the from-below approach for this particular example. Scope/effect: none of the packet's actual bound calculations is wrong, and no task dependency is blocked.
