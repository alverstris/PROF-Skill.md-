Independently: m=(f(b)-f(a))/(b-a), g(t)=f(t)-f(a)-m(t-a) is continuous/differentiable with g(a)=g(b)=0. If g≡0 every interior point works. Otherwise some value is positive or negative; the attained maximum or minimum on the closed bounded interval must then occur inside. At an interior differentiable extremum, one-sided difference quotients have opposite weak signs and their common derivative is0, so g′(c)=0 and f′(c)=m. Page3 equivalent formulas: multiplying the secant equality by b-a is exact. Replacing b by x preserves an intermediate c between a and x; the written a<c<x requires x>a. For x<a reverse that ordering. Neither existence nor uniqueness nor c=(a+x)/2 is automatic. The tangent approximation fixes f′(a), whereas MVT uses an unknown f′(c); the difference matters even when x is near a.
