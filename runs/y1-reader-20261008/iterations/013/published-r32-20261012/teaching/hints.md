<a name="d013-hints-p1"></a>

Hint P1. A polynomial meets the continuity and differentiability checks on the specified closed and open intervals. First form $`(f(4)-f(1))/(4-1)`$. Then write $`f'(c)=2c`$ and equate it to your average slope. Check the resulting input is interior; a tangent's contact point need not be an endpoint.

<a name="d013-hints-p2"></a>

Hint P2. For (a), separate negative inputs, zero, and positive inputs when checking the derivative, but calculate the secant using the two given endpoints. For (b), compare the value approached as the input tends to 1 from below with the separately assigned value at 1. Its derivative inside the interval comes only from the interior formula. The theorem's guarantee and the direct slope calculation answer different parts of the question.

<a name="d013-hints-p4"></a>

Hint P4. Put each input pair in increasing order before using the negative derivative. For the converse, differentiate $`q`$ at zero, then establish strict increase independently. One route factors $`b^3-a^3`$ for arbitrary $`a\lt b`$. The remaining quadratic factor can be written $`(a+b/2)^2+3b^2/4`$; identify when it can be zero.

Hint P5. Subtract the proposed cubic polynomial from $`e^x`$, then differentiate the entire difference. The result is exactly the difference whose positivity was given. Use a fixed positive endpoint and compare with the value at zero. For the last part, distinguish “the remainder stays positive” from “the remainder tends to zero.”

Hint P6. Move 2 to the left and name the resulting function. Check its signs at 0 and 1; the established comparison of the exponential with 1 supplies the sign at 1. That establishes a root using the supplied continuity fact. Separately, examine its derivative to see whether two distinct inputs could both give zero.
