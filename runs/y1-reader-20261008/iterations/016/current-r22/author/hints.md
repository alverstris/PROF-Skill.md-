<a name="h1"></a>
Hint P1

The common width is $`2/4=1/2`$. The right inputs are $`1/2,1,3/2,2`$; the left inputs start at 0 and end at $`3/2`$. Square each input to make a height, then multiply the sum of heights by $`1/2`$. Compare the two sums before doing all the arithmetic: all shared heights cancel in their difference, leaving only the two end heights. The curve is increasing, which decides the order of the bounds.

<a name="h2"></a>
Hint P2

The right input in strip $`i`$ is $`2i/n`$, so its height is $`2-2i/n`$. The left input is $`2(i-1)/n`$. Use the width $`2/n`$ in both sums. For the right sum, split the sum of the heights into $`2n-(2/n)\sum i`$. For the order, compare these heights within one strip: a larger input gives a smaller height here. Then add the comparisons.

[Return to P2](teaching.md#p2). [Solution P2](solutions.md#s2).

<a name="h3"></a>
Hint P3

A short interval contributes approximately $`6000t\Delta t`$ dollars. Its year-end contribution has the additional factor $`1+0.06(1-t)`$ when times are numerical years. Find principal first. For the uniform comparison, a constant rate over one year must integrate to that same principal; its interest duration is one half year on average, as in C6. Compare the weighted durations, rather than applying a full year of interest to every loan.

Hint P4

For (a), construct strip boundaries first, then locate each tag between its two boundaries. For (b), solve $`3-2x=0`$ to determine where the signed contribution changes. The graph is a line, so either triangle areas or an antiderivative can do the calculation. For (c), distinguish the fixed integration variable from the moving upper endpoint; a negative height adds a negative contribution when the endpoint moves right.
